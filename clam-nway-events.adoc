[.lead]
clam.nway EMS events occur when the Kernel Cluster Services (KCS) Connectivity, Liveliness, Availability Monitor (CLAM) is operating in an N-Way HA Configuration.


== clam.nway.ha.config
*Severity*::
INFORMATIONAL
*Description*::
This message occurs when the Kernel Cluster Services (KCS) Connectivity, Liveliness, Availability Monitor (CLAM) is operating in an N-Way HA Configuration. This EMS should be seen ONLY on OAM N-Way Clusters.
*Corrective Action*::
No action is needed.
*Syslog Message*::
CLAM is operating in an N-Way HA configuration.
*Parameters*::
(None).
