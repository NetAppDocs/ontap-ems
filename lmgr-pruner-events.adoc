= lmgr.pruner events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
lmgr.pruner events are presented when the pruner process is aborted because the Exovol transfer has commenced for SMAS-NAS or SVM Migrate which typically does not require corrective action.


== lmgr.pruner.abort.exovol
*Severity*::
INFORMATIONAL
*Description*::
This message occurs when the pruner process is aborted because the Exovol transfer has commenced for SMAS-NAS or SVM Migrate.
*Corrective Action*::
(None).
*Syslog Message*::
Abort purner as exovol transfer has commenced.
*Parameters*::
(None).
