= csm.connscalingdone events
:toc: macro

[.lead]
csm.connscalingdone events are presented when a Cluster Session Manager (CSM) session completes dynamic connection scaling to increase the connection count which typically does not require corrective action.


== csm.connScalingDone
*Severity*::
NOTICE
*Description*::
This message occurs when a Cluster Session Manager (CSM) session completes dynamic connection scaling to increase the connection count.
*Corrective Action*::
(None).
*Syslog Message*::
CSM session %s completed dynamic connection scaling.
*Parameters*::
*uniquifier* (STRING): Unique Identifier for this session.
