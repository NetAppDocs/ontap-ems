[.lead]
cf.ndustart events are presented when a nondisruptive upgrade starts which typically does not require corrective action.


== cf.nduStart
*Severity*::
NOTICE
*Description*::
This message occurs when a nondisruptive upgrade starts.
*Corrective Action*::
(None).
*Syslog Message*::
Nondisruptive upgrade started on the node "%s".
*Parameters*::
*host* (STRING): Name of system that started the nondisruptive upgrade.
