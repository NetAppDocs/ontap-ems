csm.connscalingtriggered events occur when a Cluster Session Manager (CSM) session triggers dynamic connection scaling to increase the connection count.


== csm.connScalingTriggered
*Severity*::
NOTICE
*Description*::
This message occurs when a Cluster Session Manager (CSM) session triggers dynamic connection scaling to increase the connection count.
*Corrective Action*::
(None).
*Syslog Message*::
CSM session %s triggered dynamic connection scaling.
*Parameters*::
*uniquifier* (STRING): Unique Identifier for this session.
